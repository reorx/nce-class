# 小程序：现状与上线路线

写给项目负责人和接手小程序的人：小程序现在能做什么、离正式发布还差哪几步、发布之后打算做什么。开发验证方法见 `kb/docs/verification-guide.md` 与 `kb/docs/miniapp-h5-three-role-e2e.md`，上传命令见 `kb/docs/deploy-and-ops.md`「小程序上传」，账户与邀请的业务规则见 `kb/docs/business-rules.md`「账户与邀请」。

## 一句话现状

**功能完成，合规打通，卡在人工发布流程。** 2026-09-28 核对：备案与小程序年度认证均已通过，生产后端已接真实微信登录，0.2.0 已上传为开发版，还没设体验版、没提审。生产库里没有任何真实家长用过小程序。

## 小程序现在能做什么

一个小程序，两种用户，按微信身份自动分流：

**老师**（微信账户绑定了老师登录名）

- 首页是导航中枢，显示机构与姓名，两个入口。
- 班级管理：看本机构班级；进班级后生成邀请链接、把邀请卡片分享到微信群、查看该班的加入申请并关联到学生或驳回。
- 上课记录：全机构最近课堂列表，带是否已布置作业的标记。目前是只读列表，行不可点。

**家长**（微信账户绑定了至少一个学生）

- 首页直接显示孩子最近一节课的战报，多个孩子时切换。
- 从首页进入任一历史课堂的战报。

**未绑定的账户**

- 从邀请卡片进入注册表单：填孩子中英文名、家长手机号、选一张照片，提交后等老师关联。
- 老师第一次进入时走绑定页，用老师端 Web 的登录名和密码绑定一次。

不做的事：手机号一键获取（需要企业认证，个人主体没有）、投屏实时同步、历史申请队列。

## 生产使用情况

老师端 Web 已实际使用两个多月，小程序这边是零：

| 数据 | 数量 |
|---|---|
| 班级 / 学生 / 上课记录 | 7 / 78 / 81 |
| 微信账户 | 2（都是老师绑定时产生） |
| 邀请 / 加入申请 / 家长绑定 | 0 / 0 / 0 |

这意味着首批家长导入是第一次真实检验，体验会直接决定口碑。建议先拿一个班试点，老师在群里发邀请前先把「如何注册、注册后要等老师关联」这两句话讲清楚。

## 发布路线：先发邀请版

已定的路线是先把现有功能（邀请 + 个人战报）发出去，让家长先进来绑定，战报分享到群放到下一版。理由：审核周期不确定，早提审早暴露类目和隐私声明的卡点；家长绑定是分享功能的前提，先积累绑定。

### 体验版验收（人工，按顺序）

1. mp 后台 → 版本管理：把开发版 0.2.0 设为体验版，体验成员加自己和一位真实老师。
2. 老师真机进小程序，走绑定页用 Web 登录名密码绑定。
3. 老师端 → 班级 → 生成邀请 → 分享到微信群。这是认证前被封的一步，确认卡片能弹出、群里能收到、点开落在注册表单。
4. 用另一个微信从群里点卡片，填注册表单、选照片上传、提交。
5. 老师端班级页出现待关联申请，关联到学生（有确认弹窗）或驳回。
6. 家长重进小程序，首页看到孩子的战报。
7. 提审前在 mp 后台填「用户隐私保护指引」：收集头像与照片、手填手机号、微信 openid；类目选教育；填一个老师 Web 账号作审核测试账号，供审核员走绑定流程。
8. 验收产生的邀请、申请、绑定是生产真数据，验完在老师端驳回，或让 agent 用只读之外的方式清掉。

体验版和正式版都直连生产库，不存在独立的测试环境。

### 发布之后

- 认证到期前一个月续费，否则分享被封。
- 每次改小程序代码都要手动升版本号、本地上传、后台设体验版、再提审。小程序不走 CI。

## 下一版：战报分享到微信群 + 课后处理

方案已经写好，一行代码未动，见 `kb/plans/2026-07-04-nce-class-recap-wechat-share.md`。要点：

- 分享粒度是课堂而不是学生：卡片只带课堂 id，谁点开就按谁的微信身份解析视角。老师看全班版，绑定了该班孩子的家长看自家孩子的个性化版，其他人只看到班级预览和「请联系老师获取邀请」的引导。这样分享卡片顺便成了拉新入口，也不会把别人家孩子的数据暴露给未关联账户。
- 老师端「上课记录」页的行变成可点，进入战报后一键分享到群，这就是「课后处理」入口。战报下方附上当次布置的作业。
- Web 端上课记录页的「推送全班」按钮目前是占位提示，改成引导老师去小程序分享。
- 不加表不加列。

再往后的可选项：小程序码扫码邀请、上传发版挂进发布脚本。

## 已知限制

- 个人主体：没有手机号一键获取，家长手填；年度认证每年续。
- 微信的代码校验器不认 ES2020 语法，小程序的构建目标锁在 chrome 60 / iOS 10，不要改回。
- miniprogram-ci 在 node 25 上跑不起来，上传要用 node 24。
- 体验版直连生产，没有预发环境。
